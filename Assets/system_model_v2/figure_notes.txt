SUGGESTED PAPER CAPTION
C-V2X resource allocation with shared uplink spectrum. (a) An illustrative
allocation of four V2V links over four orthogonal subchannels, each occupied
by one V2I uplink user. Each V2V transmitter is an agent that selects a
subchannel and a transmit power from {23, 10, 5} dBm, or remains silent.
Solid arrows show desired communication links; colors identify subchannels.
(b) The receiver-side expansion of subchannel 1 shows all six co-channel
interference paths among two V2V links and the V2I uplink. Dashed arrows
denote interference. Geometry is schematic and not to scale.

Configuration/env_params.py:
- n_sc = 4, n_agent default 4 (supported CLI counts 4, 8, 16).
- V2V powers = [23, 10, 5] dBm; V2I power = 23 dBm.
- Each subchannel has 1 MHz bandwidth.
- Action count = 4 * 3 + 1 = 13.
- SIG/POSIG time step = 1 ms, 50 steps per episode.

Environment/environment.py:
- map_action_to_rra: last action maps to no transmission.
- _compute_performance_and_reward: V2V transmitter to base station;
  V2I uplink user to same-subchannel V2V receiver;
  V2V transmitter to another same-subchannel V2V receiver.
- Intended V2I direction is user -> base station, not downlink.
- The base station is not an additional RL agent.

README.md and Environment/SUMOData/eval_sets/rep9_k4.csv:
- Two carriageways, three lanes in each direction.
- Twelve communication nodes in the four-agent example: four V2V Tx,
  four paired V2V Rx, four V2I users.

ILLUSTRATIVE ALLOCATION (NOT AN EXPERIMENTAL RESULT)
SC 1: U1 -> BS, T1 -> R1, T2 -> R2.
SC 2: U2 -> BS, T3 -> R3.
SC 3: U3 -> BS, T4 -> R4.
SC 4: U4 -> BS, no V2V reuse in this example.

All SC 1 interference arrows:
T2 -> R1; U1 -> R1; T1 -> R2; U1 -> R2; T1 -> BS; T2 -> BS.

The highway panel shows desired links only. SC 2 and SC 3 also have
V2I-to-V2V and V2V-to-BS interference; these are not expanded in the figure.
The illustration does not show measured vehicle separations, a real SUMO
snapshot, a learned policy, coverage radii, or motion during an episode.
Position and spacing of vehicles are chosen for schematic legibility.
